# Paper Ranking：论文影响力评估规则

请为每篇论文输出 **1–10 分** 的评分与简要理由，综合以下维度评估：

## 评估维度

1. **内容质量与主题契合度（主权重）**：阅读标题与摘要，判断论文是否真正属于 Physical AI Infra（机器人基础设施）方向，以及其技术贡献的新颖性与扎实程度。这是最重要的维度，应主导最终分数。
2. **作者最高 h-index**：作者中有领域内知名学者（h-index 高）是加分项，但不应压过内容质量本身。
3. **发表 venue**：若 venue 属于顶会顶刊白名单（RSS, CoRL, ICRA, IROS, NeurIPS, ICML, ICLR, T-RO, RA-L, IJRR），加分；arXiv 预印本不扣分但需靠内容质量说话。
4. **是否开源**：摘要或 comment 中出现 GitHub 链接是强信号，开源可复现的工作显著加分。
5. **引用数**：仅作参考。注意：对当日新发布的论文，该指标天然为 0，**不要因此扣分**。

## 输出要求

- 输出**严格 JSON 数组**，不要包含任何额外文字或解释。
- 每个元素格式：`{"arxiv_id": "...", "score": 8, "reason": "中文一句话理由", "summary_zh": "中文两句话摘要", "tweet_en": "英文推文草稿，含 arXiv 链接，不超过 270 字符"}`。
- `score` 为 1 到 10 的整数。
